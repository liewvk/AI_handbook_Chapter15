# AI Handbook — Chapter 15

Python examples accompanying Chapter 15 of the AI Handbook. The scripts demonstrate foundational concepts used in language models and neural text processing.

## Examples

| File | Topic |
| --- | --- |
| [`15.1.py`](15.1.py) | Tokenizing text with regular expressions |
| [`15.2.py`](15.2.py) | Mapping words to token IDs and decoding them |
| [`15.3.py`](15.3.py) | Storing and selecting embedding vectors with NumPy |
| [`15.4.py`](15.4.py) | Measuring vector similarity with cosine similarity |
| [`15.5.py`](15.5.py) | Converting logits to probabilities with softmax |
| [`15.6.py`](15.6.py) | Comparing softmax output at different temperatures |

## Requirements

- Python 3
- NumPy (required by `15.3.py`, `15.4.py`, `15.5.py`, and `15.6.py`)

Install NumPy with:

```bash
python -m pip install numpy
```

## Running the examples

Run a script from the repository root:

```bash
python 15.1.py
python 15.2.py
python 15.3.py
python 15.4.py
python 15.5.py
python 15.6.py
```
